All endpoints below include the **Try it** button. Enter your API key once and test any endpoint directly from the docs.

## Authentication

```
x-api-key: your_api_key_here
```

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | [Initialize On-Ramp](/api-reference/onramp) | Convert Naira → USDC |
| `POST` | [Initialize Off-Ramp](/api-reference/offramp) | Convert USDC → Naira |
| `POST` | [Initialize Swap](/api-reference/swap-init) | USDC → CNGN swap |
| `POST` | [Complete Swap](/api-reference/swap-complete) | Confirm after on-chain |
| `POST` | [Create Swap](/api-reference/swap-create) | Record swap |
| `GET` | [Get Account](/api-reference/merchant-account) | Account balance |
| `POST` | [Transfer](/api-reference/merchant-transfer) | Bank transfer |
| `POST` | [Name Enquiry](/api-reference/merchant-name-enquiry) | Validate account |
| `GET` | [Transactions](/api-reference/merchant-transactions) | Transaction history |
| `GET` | [Sub-Accounts](/api-reference/merchant-sub-accounts) | List sub-accounts |
| `GET` | [Get Sub-Account](/api-reference/merchant-get-sub-account) | Sub-account balance |
| `POST` | [Create Sub-Account](/api-reference/merchant-create-sub-account) | Create sub-account |
| `POST` | [Virtual Account](/api-reference/merchant-virtual-account) | Create virtual account |
| `GET` | [Banks](/api-reference/merchant-banks) | Supported banks |
| `POST` | [Initiate Identity Verification](/api-reference/merchant-verify-identity) | Start BVN/NIN verification |
| `POST` | [Validate Identity Verification](/api-reference/merchant-validate-identity) | Complete verification with OTP |
| `GET` | [USD/NGN Rate](/api-reference/rates) | Exchange rate |
| `GET` | [Resolve Account](/api-reference/resolve-account) | Resolve account name |
| `GET` | [All Banks](/api-reference/banks) | List all banks |
