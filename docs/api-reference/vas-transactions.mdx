---
title: "Get VAS Transactions"
description: "Get paginated list of VAS transaction history"
openapi: GET /vas/transactions
---

## Query Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `page` | number | No | 1 | Page number |
| `limit` | number | No | 10 | Items per page (max 100) |
