## Overview

AutoRamp lets you convert between Naira and stablecoins (USDC) on Base, BSC, and Stellar networks. This guide walks you through the basics.

## 1. Get Your API Key

1. Log in to the [AutoRamp Dashboard](https://autoramp.thebuidl.org/merchant/dashboard/settings)
2. Navigate to **Settings → API Keys**
3. Click **Generate New Key**
4. Copy and store it securely

<Warning>
Your API key is shown only once. If lost, generate a new one.
</Warning>

## 2. Authenticate

All requests require your API key in the header:

```
x-api-key: YOUR_API_KEY
```

See [Authentication](/authentication) for details.

## 3. Make Your First Call

### On-Ramp (Fiat → Crypto)

Convert Naira to USDC:

```bash
curl -X POST "https://api-autoramp.thebuidl.xyz/ramp/onramp" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "on",
    "network": "base",
    "amount": 50000,
    "destination": {
      "address": "0xYourWalletAddress"
    }
  }'
```

### Off-Ramp (Crypto → Fiat)

Convert USDC to Naira:

```bash
curl -X POST "https://api-autoramp.thebuidl.xyz/ramp/offramp" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "off",
    "network": "base",
    "amount": 50000,
    "destination": {
      "bankCode": "058",
      "accountNumber": "0123456789"
    }
  }'
```

### Stellar On-Ramp / Off-Ramp

For the Stellar network, the on-ramp returns a Bitnob NGN virtual account to fund, and the off-ramp returns a Stellar USDC funding address:

```bash
# Off-ramp: USDC (Stellar) → Naira
curl -X POST "https://api-autoramp.thebuidl.xyz/ramp/offramp" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "off",
    "network": "stellar",
    "amount": 50000,
    "sourceAddress": "GXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
    "destination": {
      "bankCode": "058",
      "accountNumber": "0123456789"
    }
  }'
```

The off-ramp response includes a `deposit` object with `receiveAddress`, `amount`, `memo`, and `validUntil` — send the exact USDC amount to that Stellar address to complete the payout.

## 4. Check Transaction Status

```bash
curl -X GET "https://api-autoramp.thebuidl.xyz/ramp/transactions?reference=YOUR_REFERENCE" \
  -H "x-api-key: YOUR_API_KEY"
```

## 5. Set Up Webhooks

Configure your webhook URL in the dashboard to receive real-time transaction updates when statuses change.

See [Webhooks Overview](/webhooks/overview) for payload details and [Verify Webhooks](/webhooks/verify) for signature verification.
